PERMISSIONS & CONTROL

Connected with seller authorisation.

The planned connection will use eBay’s authorised API access. Financial information is available for the seller account that grants access, subject to eBay’s supported marketplaces and records.

  • Reconcile Ready will not ask for an eBay password
  • Financial records can appear after payment processing completes
  • Coverage depends on eBay API availability and seller permissions
